## Toskr 1.0.2

### 钉图

- **拖动更顺手** 按住钉图任意位置即可拖动，拖出钉图范围也不会断。
- **拖边缘缩放** 拖四边或四角按原比例缩放（20%–400%），对边 / 对角保持不动，缩放时显示当前比例。
- **滚轮以指针为中心缩放** 指着哪里，放大缩小时那里就不动；指针停在钉图边缘也能用滚轮缩放。

### 隐私

- **发给 AI 前先确认敏感内容** 润色、翻译、拆子任务等 AI 功能发出请求前，会检查要发送的内容；含密钥、证件号、邮箱等敏感信息时先弹窗，写明是哪条内容、用途、AI 服务和命中的类别，你确认后才发送。内容太长无法完整检查时直接不发。
- **超长文本不再绕过隐私检查** 隐私检查开着时，要粘贴的文字超出本地检查上限会中止发送，发送结果里记为「超出隐私扫描上限」。

### 确认窗

- 删除密钥、清空剪贴板历史、清除使用统计等确认改为 Toskr 自己的确认窗，跟随当前主题与浅色 / 深色。
- 按 Esc 一律取消。删除这类操作需要按 ⌘⏎ 或点按钮确认，单按回车不会执行。之前在系统确认框里按 Esc，可能会执行删除。

### 改进

- 详情窗阅读时划选文字，工具条贴在选中文字旁边，不再跑到窗口底部。
- 固定（📌）的详情窗在阅读状态时，从面板发送剪贴卡会照常发到目标应用，不会被加进这张卡；进入编辑后才加进卡。
- 面板默认保持展开，不随切换应用收起。
- 底部键位提示改为常驻，去掉了开关。
- 引导和提示里的「双击 ⇧」改为写出键名「双击 ⇧ Shift」。

### 修复

- 列表里有内容很长（几 MB）的文字卡片时，面板卡住无响应。
- 用 Tab 选中卡片拖动把手后切到剪贴页或搜索，按空格没有反应。

### 下载

| 机型 | 文件 |
| --- | --- |
| Apple Silicon（M 系列） | `toskr-1.0.2-arm64.dmg` |
| Intel | `toskr-1.0.2-amd64.dmg` |

已安装 1.0 或 0.x 的，在应用里点「更新」即可。新安装需要 macOS 13 或更高版本，首次打开请右键 →「打开」，并按引导授予辅助功能与输入监控两项权限。

其余文件（`Toskr.app.tar.gz`、`latest.json`、`update-*.json` 等）供应用内自动更新使用，不需要手动下载。
