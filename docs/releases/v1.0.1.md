## Toskr 1.0.1

### 新增

- **分组排序** 分组右键或「…」→「排序」：手动 / 发送最多 / 最近发送，每个分组单独设置；自动排序的分组标题旁有图标标明。适合配合「发送后保留」做常用提示词库。
- **发送次数长期记录** 卡片页脚的「已发送 ×N」不再只算最近 200 次发送；右键「清零发送次数」可以把一张卡降回去，可撤销。
- **详情窗点别处即保存** 标签、图片文字备注、图片说明输入到一半，点窗口里别处就保存并收起，不用再按回车。

### 全局快捷键

- 录制时支持 `;` `'` `,` `.` `/` `\` `[` `]` `-` `=` 等符号键（如 `⇧⌘;`）。之前按这些键不会被录下，看起来像设置成功了。
- 录到已被系统占用的组合（截屏、输入法切换、调度中心等，按你在「键盘快捷键」里的实际设置判断），或 `⌘C` 这类只按 ⌘ 的通用命令时，直接提示换一个，不再录上了却按不出来。
- 新安装时「开关面板」默认为 `⇧⌘C`（与 0.x 版相同）。已设置过的不变。

### 修复

- 把面板拖向屏幕右缘时，偶尔整个消失而不是贴边。
- 贴边面板滑回、滑出几次后，偶尔不再贴边、点击屏幕右缘也唤不出来。
