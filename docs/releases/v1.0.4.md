## Toskr 1.0.4

### 截图

- **标注后还能调选区** 画了箭头、矩形之后，拖边角可以继续扩缩选区；退出工具后可拖动平移，方向键微调（⇧ 加大步长）。
- **选区与标注一起撤销** ⌘Z / ⇧⌘Z 同时撤销、重做标注和选区的改动；连续按方向键微调合并成一步。
- **边缘吸附** 拖动选区时靠近窗口边缘会轻轻吸住并显示参考线，按住 ⌥ 或 ⌘ 临时关闭。
- **批注编号只算选区内的** 缩小选区把批注裁出去后，编号和导出的说明自动只算留下的。
- **长截屏更稳** 重写了滚动拼接：缩放屏的亚像素滚动、浮动滚动条、吸顶栏都不再导致「接不上」。
- 工具条悬停提示恢复正常显示，文案精简。

### 详情窗

- **标题栏** 单行居中显示「标题 · 来源 · 时间」，完整时间和字数放在悬停提示里。
- **标签** 默认收起，点「#N」展开；标签多时自动折行。
- **能力提示卡** 阅读时显示划词即改、选词发送、一稿多投、化名保护的入口，可在设置里关闭。
- **窄窗口** 操作坞放不下时，次要操作收进「⋯」菜单，发送按钮始终完整。
- 正文滚动后，标题栏下方不再与正文叠字。

### 改进

- 菜单、气泡、浮条、分组速览等浮层统一成细描边加柔和投影，在各配色方案下一致。
- 分组速览弹出和切换更顺；弹框已开着时，移到另一个合上的分组会立即切换。
- 收件箱可整批操作：全部归到某组、全部完成、全部删除，都能撤销。
- 常用区「取消常用」可以撤销。

### 修复

- 面板停在副屏边缘时，按空格打开的详情窗跑到主屏。
- 常用区方块右键「取消常用」时闪退。
- 常用区方块点击时手稍微一动就不发送。
- 应用意外退出时会留下记录，下次启动写进诊断日志，便于排查。

已安装 1.0 或 0.x 的，在应用里点「更新」即可。新安装需要 macOS 13 或更高版本，首次打开请右键 →「打开」，并按引导授予辅助功能与输入监控两项权限。

其余文件（`Toskr.app.tar.gz`、`latest.json`、`update-*.json` 等）供应用内自动更新使用，不需要手动下载。
