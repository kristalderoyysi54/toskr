## Toskr 1.0.3

### 收件箱

- **底部抽屉** 建了自己的分组后，收件箱收到笔记列表底部，平时只露一行（条数 + 最新一条），点一下展开。
- **按去向分堆** 展开后，建议去同一个分组的内容排成一堆，点「归入」整堆送过去；「按建议归好 N 条」一次归完所有有建议的。两者都能撤销。
- **逐条整理** 一条一条过：归到建议的分组、换一个分组、留下或删除。
- **捕获时直接选去向** 划词捕获成功的气泡上给出 2–3 个建议分组，点一下就归好。
- 剪贴卡可以「收下」到分组，也可以设提醒。

### 笔记列表

- **分组大边框** 每个分组一个框，分组颜色融进边框和悬停底色；分组头用小文件夹表示展开 / 合上。
- **卡片样式** 标题和正文在上、图片在下；多张图排成一行小缩略图，很长的图只显示顶部。
- **合上的分组悬停速览** 鼠标停在合上的分组上约 0.4 秒，面板旁边弹出这一组的内容列表，可以搜索，点一条直接发送，不用先展开。行上右键是卡片菜单，带图的行悬停会弹出原图。
- **常用区** 常用的内容排成方块，点一下发送，连点也只发一次。
- **拖动换组** 拖动卡片时列表顶部出现分组坞，可以放进别的分组或新建分组；拖到合上的分组上停一下会自动展开。左侧分组栏已移除。
- 新建分组、全部展开 / 折叠、紧凑列表、清理已完成收进标题栏的 ☰ 菜单。

### 改进

- 设置新增「减弱动态效果」，关掉界面里的过渡和弹性动画。
- 剪贴页卡片悬停的操作钮改成和笔记页一样的一条浮起工具条。
- 任务页分组头改用小文件夹；拖任务到合上的分组上时文件夹会预开。
- 列表里内容很多时滚动更顺。

### 修复

- 菜单打开时按截图快捷键没有反应。

### 下载

| 机型 | 文件 |
| --- | --- |
| Apple Silicon（M 系列） | `toskr-1.0.3-arm64.dmg` |
| Intel | `toskr-1.0.3-amd64.dmg` |

已安装 1.0 或 0.x 的，在应用里点「更新」即可。新安装需要 macOS 13 或更高版本，首次打开请右键 →「打开」，并按引导授予辅助功能与输入监控两项权限。

其余文件（`Toskr.app.tar.gz`、`latest.json`、`update-*.json` 等）供应用内自动更新使用，不需要手动下载。
