## Toskr 1.0.0：原生重写

界面与后台整体改为 macOS 原生实现，不再内嵌浏览器内核。功能与数据沿用 0.22。

### 从旧版升级

- 在旧版里点「更新」即可，重启后就是 1.0。
- 笔记、剪贴历史、任务、账单、秘文、图片和设置原样保留，不需要迁移或重新设置；自定义过数据目录的也一样。
- 辅助功能、输入监控和钥匙串授权沿用，不会再弹授权框。
- 旧版的数据文件不会被改动。万一数据没接上，面板顶部会说明原因并给出「重试」，不会显示成空白。

### 更快、更省

| | 1.0 | 0.22 |
| --- | --- | --- |
| 打开到可用 | 约 0.2 秒 | 3–4 秒 |
| 启动 20 秒后的内存 | 60–90 MB | 约 270 MB |

<sub>2026-11-11 在同一台 Apple Silicon Mac 上各重启两次测得，数据量约 750 条；长时间使用后内存会高于此值。</sub>

### 新增

- **同时问多个 AI** 一次发到 2–3 个应用，收回的回复并排对比：各家都说到的内容压淡，只有一家说到的加浅底。
- **AI 改写逐块核对** 结果边生成边显示，按改动块逐字标出增删，可逐块采纳或还原，`⌘ Enter` 全部采纳。
- **截图文字按行挑选** 识别后点选、连选或框选要的几行再复制；选区里的二维码直接读出内容。
- **今天页时间块** 把任务拖进时间轴排期，拖下沿改时长，与日历日程同轴显示。
- **任务速记本地解析** 输入「明天下午 3 点开会 !!」，不配置 AI 也能认出时间、重复、优先级和分组。
- **订阅洞察** 近 6 个月分类柱图、未来 30 天扣款时间线、涨价提示。
- **详情窗阅读辅助** `⌘ F` 文内查找、标题大纲、阅读进度。
- **命令面板** `⌘ K` 执行动作，或搜索卡片与任务。
- **Intel 版本** 首次提供 Intel Mac 安装包。

### 下载

| 机型 | 文件 |
| --- | --- |
| Apple Silicon（M 系列） | `toskr-1.0.0-arm64.dmg` |
| Intel | `toskr-1.0.0-amd64.dmg` |

需要 macOS 13 或更高版本。首次安装请右键 →「打开」，并按引导授予辅助功能与输入监控两项权限。本机中英互译需要 macOS 15。

其余文件（`Toskr.app.tar.gz`、`latest.json`、`update-*.json` 等）供应用内自动更新使用，不需要手动下载。
