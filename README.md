# Toskr

**AI 消息中转站**

把各个应用里的文字和图片收进来，整理、组合并检查隐私，再粘贴到当前 AI 输入框。

> **来源应用里的文字和图片** → **Toskr 收集、整理和隐私检查** → **当前 AI 输入框**

> 应用界面支持简体中文与英文，默认跟随 macOS 系统语言，可在 设置 → 窗口与外观 → 语言 切换。

## 1.0：原生重写

界面与后台整体改为 macOS 原生实现，不再内嵌浏览器内核。功能与数据沿用旧版，从旧版点「更新」即可，不需要迁移或重新设置。

| | 1.0 | 0.22 |
| --- | --- | --- |
| 打开到可用 | 约 0.2 秒 | 3–4 秒 |
| 启动 20 秒后的内存 | 60–90 MB | 约 270 MB |

<sub>2026-11-11 在同一台 Apple Silicon Mac 上各重启两次测得，数据量约 750 条；长时间使用后内存会高于此值。</sub>

### 1.0 新增

- **同时问多个 AI** 一次发到 2–3 个应用，收回的回复并排对比：各家都说到的内容压淡，只有一家说到的加浅底
- **AI 改写逐块核对** 结果边生成边显示，按改动块逐字标出增删，可逐块采纳或还原，`⌘ Enter` 全部采纳
- **截图文字按行挑选** 识别后点选、连选或框选要的几行再复制；选区里的二维码直接读出内容
- **今天页时间块** 把任务拖进时间轴排期，拖下沿改时长，与日历日程同轴显示
- **任务速记本地解析** 输入「明天下午 3 点开会 !!」，不配置 AI 也能认出时间、重复、优先级和分组
- **订阅洞察** 近 6 个月分类柱图、未来 30 天扣款时间线、涨价提示
- **详情窗阅读辅助** `⌘ F` 文内查找、标题大纲、阅读进度

## 三步上手

1. **收进来** 选中文字后双击 `⇧ Shift`。复制过的文字和图片也会进入剪贴板历史。
2. **整理好** 选择一张或多张卡片，调整顺序，组成这次要用的一组内容。需要时先处理文字或图片里的隐私。
3. **粘贴过去** 先点进目标应用的输入框，再打开 Toskr 按 `⌘ Enter`。Toskr 会切回该应用并粘贴；开启自动提交的应用，回车也一并完成。

## 核心能力

- **跨应用收集** 捕获任意应用中选中的文字，也能取回剪贴板历史里的文字和图片
- **多项内容一起准备** 选择多张文字或图片卡片，按当前顺序组成一次投递
- **粘贴前检查文字隐私** 在本机识别邮箱、IP、手机号、密钥等支持的敏感文字，需要时替换后再粘贴
- **处理图片中的敏感文字** 使用本地 OCR 找出支持识别的区域，并在发送副本上遮挡，原图保持不变
- **发送前对比** 左「原文」右「将发送」逐行对照，替换掉的内容逐字标出，可在窗口里直接还原或保留
- **本机加密存储** 笔记、图片与消息记录以 AES-256-GCM 加密落盘，密钥存放在 macOS 登录钥匙串，其他应用无法读取或篡改

## 顺手能力

- **剪贴板历史** 默认保留 30 天，可随时暂停
- **区域截图** `⌃ ⌥ A` 截图并标注，支持长截屏、钉在屏幕上、识别文字；macOS 15 起可本机中英互译
- **笔记和任务** 暂存 Prompt、资料和待办，Toskr 运行时会提醒到期任务；可与「提醒事项」双向同步，并在今天页显示日历日程
- **提示词模板** 选好卡片后「用模板发送」，按当前目标应用推荐常用模板
- **命令面板** `⌘ K` 执行动作，或搜索卡片与任务
- **面板停靠** 可固定在屏幕右侧或下方，也可开启左右伴随模式
- **按需扩展** 消息工作台、秘文、订阅提醒和 AI 助手默认关闭，需要时再开启

## 使用边界

- Toskr 识别的是目标应用，不是具体聊天、窗口或浏览器标签页。粘贴前请确认当前输入框。
- 图片 OCR 只处理支持识别的敏感文字，不识别人脸、二维码或所有视觉隐私。
- 核心记录与隐私处理默认在本机，无账号、无遥测。可选 AI、远程图片、链接摘要、汇率和更新检查等功能可能联网。
- 剪贴板捕获和任务提醒只在 Toskr 运行时工作。
- 加密存储防的是其他应用离线读取或篡改数据文件，不防已解锁本机上的内存级取证。导出的完整备份是明文，用于跨机迁移，也是钥匙串密钥丢失时唯一的恢复通道——请妥善保管并定期导出。

## 安装

需要 **macOS 13 或更高版本**；1.0 仅支持 Apple Silicon。

1. 从 [最新 Releases](https://github.com/kristalderoyysi54/toskr/releases/latest) 下载 `.dmg`，拖入 `Applications`。
2. 首次启动时使用**右键 →「打开」**，以打开自签名应用。
3. 按引导在「系统设置 → 隐私与安全性」中授予两项权限。
   - **辅助功能** 用于读取所选文字、切回目标应用并执行粘贴
   - **输入监控** 用于识别全局双击 `⇧ Shift`

应用内置自动更新，也可在「设置 → 关于」中手动检查。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 双击 `⇧ Shift` | 有选中文字时收进 Toskr，无选中时呼出或收起面板 |
| `⌘ Enter` / `⌘ 1-9` | 粘贴已选卡片 / 快速粘贴第 N 张卡片 |
| `⌘ F` · `Esc` | 搜索 · 逐层退出 |
| `⌘ K` | 命令面板 |
| `⌃ ⌥ A` | 区域截图 |
| 长按 `⌥ Option` | 打开完整快捷键速查层 |
